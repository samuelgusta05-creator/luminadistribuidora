# Lúmina — Landing Page B2B

Landing page repaginada para a distribuidora de cosméticos de luxo **Lúmina**, desenvolvida com **Next.js (App Router)**, **React**, **TypeScript** e **Tailwind CSS**, seguindo as diretrizes visuais e tokens do **Refero Styles**.

## 🚀 Tecnologias
- **Next.js 14+** (App Router)
- **React 18**
- **TypeScript**
- **Tailwind CSS**
- **Google Fonts** (`Cormorant Garamond` e `Plus Jakarta Sans`)

## 📦 Estrutura de Pastas
```
src/
├── app/
│   ├── layout.tsx
│   ├── page.tsx
│   └── globals.css
├── components/
│   ├── Header.tsx
│   ├── Hero.tsx
│   ├── Brands.tsx
│   ├── Features.tsx
│   ├── ProductGrid.tsx
│   ├── Testimonials.tsx
│   ├── LocationSection.tsx
│   └── Footer.tsx
└── types/
    └── index.ts
```

## 🛠️ Como Executar Localmente
1. Instale as dependências:
```bash
npm install
```
2. Inicie o servidor de desenvolvimento:
```bash
npm run dev
```
3. Abra no navegador: `http://localhost:3000`
